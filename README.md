# Personal Event Planner

A React + Vite web application that allows users to create, manage, and track personal or professional events such as
meetings, appointments, and social activities.

The app uses React, Context API, and Bootstrap for styling and state management.

## Features

- User registration and login system
- Create, edit, and delete events
- Dashboard to view all upcoming events
- Event validation
- Persistent data using localStorage
- Help page with usage instructions
- Responsive design using Bootstrap

## Installation

1. Clone or download the repository
   git clone https://github.com/SZStanton/Event-Planner

2. Navigate into the project folder

3. Install the dependencies with:
   npm install

4. Run the App
   npm run dev

5. Open the webpage on your browser
   http://localhost:5173/
